SchemaUI — custom frontend example

A framework-free proof that /api/v1/* is a real, versioned contract: this page is plain HTML and JS with no build step, pointed at by --frontend examples/frontend. It renders the schema's top-level scalar fields — enough to prove the wire format, not a replacement for the bundled React UI (arrays, composites and key/value maps show as "unsupported" here rather than being reimplemented twice).
